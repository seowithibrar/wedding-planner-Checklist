## Cómo elegir el lugar perfecto para tu boda

El lugar marca el tono, la fecha y el marco de presupuesto de toda tu celebración.

<PlannerQuote author="David Sterling" role="Especialista en contratación de lugares">
No firmes nunca el contrato de un lugar sin haber recorrido el espacio a la misma hora del día en que será tu ceremonia, para comprobar la posición del sol y la acústica.
</PlannerQuote>

<CalloutBox type="warning" title="Alerta de costes ocultos">
Un presupuesto base de 10.000 $ puede llegar fácilmente a 14.000 $ al sumar un 22 % de tarifa de servicio, un 8 % de impuestos estatales y el personal de seguridad obligatorio.
</CalloutBox>

### Preguntas imprescindibles para la visita
1. ¿Está libre nuestra fecha? ¿Qué tarifas hay en temporada alta y baja?
2. ¿Cuál es el aforo exacto para una cena sentada y para un cóctel?
3. ¿Qué espacio de plan B hay para la lluvia si la ceremonia es al aire libre?
4. ¿Hay restricciones de ruido o un horario temprano de fin de la música?
5. ¿Dónde están la mejor luz natural y los mejores rincones para retratos? (Durante la visita, anota los lugares más bonitos y la orientación del atardecer, y después repasa nuestras [poses de fotografía de boda para principiantes](/blog/wedding-photography-poses-for-beginners) para planificar las sesiones de fotos en pareja y en familia).
6. ¿Qué proveedores son obligatorios, recomendados o no están permitidos? ¿Podemos traer nuestro propio catering, servicio de barra o decorador?
7. ¿A qué hora pueden llegar los proveedores para montar y cuándo tiene que estar todo recogido?
8. ¿Qué incluye el precio: mesas, sillas, mantelería, cristalería, iluminación, equipo de sonido o personal?
9. ¿Cuál es el calendario de pagos, la política de cancelación y las condiciones para cambiar de fecha?
10. ¿Hay aparcamiento, acceso adaptado y aseos para invitados con movilidad reducida?

## Paso 1: fija el presupuesto del lugar antes de buscar

El lugar, junto con el catering, suele llevarse la mayor parte del presupuesto de una boda, a menudo entre el 40 y el 50 % entre los dos. Decide un máximo antes de buscar e incluye los extras que se olvidan con facilidad: cargos por servicio, impuestos, seguridad, limpieza, cargos por cortar la tarta o por descorche y cualquier alquiler que el lugar no incluya. Usa la [Calculadora de presupuesto de boda](/tools/budget-calculator) para ver cuánto deja tu total para el lugar.

## Paso 2: conoce primero el número de invitados

El número de invitados decide qué lugares son siquiera posibles. Un lugar demasiado pequeño resulta agobiante y puede superar los límites de seguridad, mientras que uno demasiado grande parece vacío. Prepara primero un borrador de la lista con nuestra [guía para organizar la lista de invitados](/blog/perfect-guest-list-guide), y después busca salones que acomoden bien a ese número para una cena sentada, con espacio para la pista de baile, la barra y un bufé si lo necesitas.

## Paso 3: elige el tipo de lugar

| Tipo de lugar | Ideal para | Ten en cuenta |
| --- | --- | --- |
| Hotel o salón de banquetes | Planificación todo en uno, listas grandes, invitados que necesitan habitación | Consumos mínimos de comida y bebida, menos libertad con los proveedores |
| Restaurante | Bodas pequeñas, buena comida, planificación sencilla | Poco espacio para bailar, horarios de cierre fijos |
| Granero o finca | Estilo rústico, ceremonias al aire libre | Alquileres, electricidad, aseos y plan para la lluvia a menudo aparte |
| Jardín o parque | Fondos naturales y ceremonias de día | Permisos, tiempo, límites de ruido, poca sombra |
| Casa histórica o museo | Fotos con carácter y personalidad | Normas estrictas sobre velas, decoración y horarios |
| Casa particular o jardín propio | Ambiente personal, horarios flexibles | Carpas, generadores, aseos, aparcamiento y seguro, como explica nuestra [lista para una boda en casa](/checklists/backyard-wedding-checklist) |
| Resort en el destino | Celebraciones de fin de semana y viajes | Coste del viaje para los invitados y requisitos legales, como explica nuestra [lista para una boda en el extranjero](/checklists/destination-wedding-checklist) |

## Paso 4: preselecciona en internet y visita en persona

Reduce tu lista a entre cuatro y seis lugares fijándote en las fotos, las opiniones, el aforo y los precios publicados. Después, visítalos en persona. En cada visita:

- Ve a la misma hora del día que la ceremonia para ver la luz real.
- Recorre el camino que harán los invitados: del aparcamiento a la ceremonia, la zona del cóctel, la recepción y los aseos.
- Pide ver el lugar preparado para otro evento, o fotos de una boda con tu número de invitados.
- Fotografía cada espacio y toma notas enseguida, porque los lugares se confunden a partir de la tercera visita.
- Pregunta qué otros eventos podría haber a la misma hora en tu fecha.

## Paso 5: compara los lugares en igualdad de condiciones

Los presupuestos casi nunca tienen el mismo formato. Prepara una comparación sencilla para ver el coste real:

| Partida | Lugar A | Lugar B | Lugar C |
| --- | --- | --- | --- |
| Alquiler base o consumo mínimo | | | |
| Catering por invitado | | | |
| Cargo por servicio e impuestos | | | |
| Alquileres no incluidos | | | |
| Extras obligatorios (seguridad, limpieza) | | | |
| Coste total estimado | | | |
| Aforo para cena sentada | | | |
| Plan para la lluvia | | | |

Rellena la tabla durante cada visita. El lugar con el precio inicial más bajo a menudo no es el más barato cuando se suma todo.

## Paso 6: lee el contrato con atención

Antes de firmar, comprueba que el contrato indica con claridad:

- La fecha exacta, las horas de inicio y fin, y los salones o espacios incluidos.
- El precio total, todo lo que incluye y cada cargo adicional.
- El importe del anticipo, el calendario de pagos y las fechas de vencimiento.
- Las condiciones de cancelación y de cambio de fecha, tanto para ti como para el lugar.
- El plan para la lluvia y quién decide cuándo se usa.
- Las normas sobre decoración, velas, confeti, volumen de la música y acceso de los proveedores.
- Los requisitos de seguro y cualquier límite de responsabilidad.

Pide que se añada por escrito todo lo que el coordinador te haya prometido de palabra. Apunta cada fecha de pago en el [Calendario de planificación de boda](/tools/wedding-planning-calendar).

## Señales de alerta

- El lugar no quiere darte un presupuesto detallado por escrito.
- Las opiniones hablan de cargos sorpresa, reservas duplicadas o personal maleducado el día de la boda.
- El coordinador responde con vaguedades sobre qué pasa si llueve.
- El contrato permite al lugar cambiar tu salón o tu fecha sin tu consentimiento.
- Te presionan para firmar el mismo día con un precio «solo por hoy».

## Cuándo reservar el lugar

Los lugares más solicitados se reservan con entre 12 y 18 meses de antelación para los sábados de temporada alta. Si tienes menos tiempo, mira viernes, domingos, días laborables o la temporada baja, y valora tipos de lugar que se llenan menos rápido, como restaurantes o espacios privados. Nuestra [lista de planificación de boda de 12 meses](/checklists/12-month-wedding-planning-checklist) muestra qué reservar justo después del lugar, y la [lista de planificación de boda de 3 meses](/checklists/3-month-wedding-planning-checklist) explica cómo encontrar lugar con poco tiempo.

## Preguntas sobre el equipo del lugar

Las personas que gestionan el lugar importan tanto como el propio espacio:

- ¿Tendremos un coordinador asignado y estará presente el día de la boda?
- ¿Cuántas bodas celebra el lugar cada fin de semana?
- ¿Quién se encarga del montaje y la limpieza, y con qué horarios?
- ¿A quién llamamos si algo sale mal ese día?
- ¿Podemos ver el espacio durante otro evento o hablar con una pareja reciente?

Un equipo organizado y que responde rápido es una buena señal de cómo se gestionará tu boda. Las respuestas lentas y vagas antes de firmar suelen significar lo mismo después de firmar.

## Accesibilidad y comodidad de los invitados

Comprueba que todos los invitados puedan disfrutar del día: recorridos sin escalones, aseos adaptados, asientos para los invitados mayores durante la ceremonia, sombra o calefacción, y suficiente aparcamiento u opciones de transporte. Son detalles fáciles de pasar por alto en una visita y difíciles de arreglar después.

## Después de reservar el lugar

Cuando el contrato esté firmado, comparte los datos del lugar con tu fotógrafo, tu catering y tu organizador, pide el plano del espacio y apunta cada plazo que te dé el lugar, como la fecha del número final de invitados y el último día para cambiar el menú.

## Lista para elegir el lugar

- Fija un presupuesto máximo para el lugar, con cargos e impuestos.
- Acordad un borrador del número de invitados.
- Decidid la temporada, el día de la semana y dos o tres fechas alternativas.
- Elegid dos o tres tipos de lugar.
- Preseleccionad entre cuatro y seis lugares en internet.
- Visitad cada lugar a la hora de la ceremonia.
- Haced todas las preguntas de la visita y anotad las respuestas.
- Comparad los costes completos en una tabla.
- Leed el contrato, pedid los cambios por escrito y confirmad los requisitos de seguro.
- Pagad el anticipo y apuntad todas las fechas de pago en el calendario.
