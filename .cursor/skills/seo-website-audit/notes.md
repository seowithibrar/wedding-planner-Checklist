# SEO Website Audit Notes

## Optional deeper checks

- Compare top-ranking competitors if the user wants competitive context
- Review Core Web Vitals evidence if performance data is available
- Check local SEO signals if the site is location-based
- Check blog content clusters if the site is content-heavy

## Suggested priority scale

- Critical: blocks indexing, crawlability, or core conversions
- High: likely meaningful ranking or UX impact
- Medium: worthwhile improvement
- Low: polish or nice-to-have
