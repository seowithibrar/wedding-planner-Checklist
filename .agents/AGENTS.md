
# Production Domain Rule
Always use the production domain: https://www.weddingplanningchecklists.org/
Never copy or reuse placeholder content, demo templates, sample data, or hardcoded values from any local HTML template.
Never insert or regenerate any placeholder brand names such as Evera, Demo, Template, Sample, Lorem Ipsum, Test Brand, or any other default theme content.
Before publishing or updating any page, automatically scan for Brand names, Author names, Footer text, Copyright, Site title, Logo references, Social links, Email addresses, Phone numbers, URLs.
If any placeholder content is detected, stop the update and replace it with the correct production website content. Never ask for confirmation.
Every page must use the branding from: https://www.weddingplanningchecklists.org/
Author boxes, footer, header, CTA sections, navigation, internal links, schema, and metadata must always match the production website.
Never overwrite existing production branding with template branding.
Before every deployment, perform an automatic validation for No 'Evera', No demo content, No placeholder text, No broken links, No template assets, No sample logos.
If production content cannot be determined, stop the task and ask for clarification instead of inserting placeholder values.
This Production Domain Rule has higher priority than any template, theme, HTML file, or previous instruction.

# WeddingPlanningChecklists.org – Universal Blog Post Design & Content Rules

## 1. Consistent Blog Structure
Every article must follow this order:
1. Breadcrumb Navigation
2. Featured Hero Image
3. Category Badge
4. H1 Title
5. Article Metadata (Author, Updated Date, Reading Time)
6. Short Introduction (2–4 paragraphs)
7. Quick Summary / Key Takeaways Box
8. Interactive Checklist Preview / Download Banner
9. Sticky Table of Contents
10. Main Content (including Timeline Sections, Comparison Tables, Expert Advice Quotes, & Callout Boxes)
11. FAQ Section (minimum 8 questions with Schema)
12. Conclusion + Next Steps
13. Related Articles
14. Newsletter / Download Printable CTA
15. Author Box

## 6. Content Block Rules
Use a rich mix of reusable content blocks to enhance engagement and readability:
* **Interactive Checklist Card:** Checkable items with visual progress tracking.
* **Printable PDF / Spreadsheet Download Banner:** Prominent mid-article asset download card.
* **Expert Advice & Planner Quotes:** Styled blockquotes featuring certified wedding planner quotes and industry tips.
* **Comparison Tables:** Clean responsive tables comparing timelines, budgets, vendor priorities, or package styles.
* **Timeline Stepper / Step Cards:** Numbered visual indicators for step-by-step phases.
* **Callout Boxes:** Highlighted Tip Box, Warning Box, Quick Facts, and Key Takeaways.
* **FAQ Accordion:** Interactive expandable Q&A matching Google FAQ Schema requirements.
Do not repeat the same block excessively.
